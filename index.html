01 / Audit Lead capability · implemented locally

Cross-check the document set before a wrong revision travels

Audit examines relationships across an approved set of controlled documents. It surfaces cited candidates for an engineer to inspect; it does not make the decision for them.

  1. 01 · Cross-check

    Review the approved set

    Cortessa checks for supersession, broken references, stale content and terminology conflicts across documents.

  2. 02 · Show the source

    Open the evidence

    Each candidate finding points back to the cited passages so the issue can be checked in context.

  3. 03 · Human decision

    Review and decide

    The engineer records the disposition and retains approval authority. Cortessa never certifies.

02 / Why it is different A source check outside the model

A prompt is an instruction. Cortessa adds a separate check.

A general-purpose language model can be told to cite sources and refuse when unsure. That instruction is still interpreted by the same model producing the answer. Cortessa checks the output separately before presenting any claim as Verified.

  • The prompt

    The model interprets it

    A request to cite or refuse guides the answer, but it is not an independent acceptance rule.

  • The Cortessa gate

    A deterministic rule checks it

    A versioned rule outside the model decides whether each claim is eligible for Verified, Draft or Refused.

  • The human decision

    The source stays open

    Verified attests that the claim occurs in the cited source; it does not certify correctness. A person decides.

05 / Target architecture Governed offline revision exchange

Local intelligence. Site-wide document continuity.

Each engineer box runs its approved documents, ingestion, index, model, Audit and Ask locally. The target site architecture connects those boxes through departmental nodes to an on-site hub, entirely inside the site boundary.

Only explicitly approved, signed revisions are designed to move. An AI answer does not become site truth, and receiving a revision does not silently add it to another engineer's searchable document set.

  1. Engineer boxes
    • Approved local documents
    • Audit · Ask
    • Human approval
  2. Departmental nodes
    • Permission-scoped exchange
    • Signed revisions
    • Visible history
  3. On-site hub
    • Permitted information only
    • Conflicts remain visible
    • No central approval

06 / Source status Deterministic · versioned · human reviewed

Verified, Draft or Refused — never a hidden confidence score

The source check records what can be established from the cited material. It does not decide whether the source itself is correct.

Verified

The claim is provably a near-verbatim span of the cited source.

Draft

The claim cannot be proven against the source and is not passed off as fact.

Refused

The required fact is not present, so the system refuses rather than guess.
